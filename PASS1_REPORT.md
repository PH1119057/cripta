# Проход 1 — воспроизводимый baseline

Дата проверки: 2026-08-13.

## Что изменено

- Удалены переносимая только внутри старой установки `.venv`, кэши, временные БД,
  старые `build`/`dist` и скриншоты.
- Добавлен `uv.lock` с hashes и полным набором `dev`, `build`, `history` зависимостей.
- Поддерживаемый Python ограничен диапазоном `>=3.12,<3.14`.
- Локальная Windows-установка зафиксирована на Python 3.13.x и `uv 0.11.33`.
- Добавлены PowerShell-скрипты установки и полной проверки.
- Windows CI проверяет Python 3.12 и 3.13 из lock-файла.
- Исправлено подавление отсутствующих type stubs у опционального `pyarrow`.
