# EO4 — причинное сопровождение позиции по структуре зон

EO4 — исследование, а не торговое правило. Entry не меняется: используются 846 фактических входов EO2 на `−0,20%` от исходной зоны.

Одним проходом сравниваются четыре варианта: неизменный `−1/+1,10`; ранний выход после подтверждённого разрушения защитной зоны; сохранение сильного движения после подтверждённого пробоя препятствия; гибридная машина состояний.

Событие становится доступно алгоритму только в `outcome_at`. Выход выполняется не задним числом по уровню, а по первой закрытой минуте после подтверждения. Уже выставленные hard stop и target исполняются внутри минуты до решения, возникающего только на её закрытии; если hard stop и target видны в одной минуте, применяется неблагоприятный порядок.

Гибрид использует заранее зафиксированные состояния `EARLY`, `HEALTHY`, `PROVEN`, `RUNNER`, `WARNING`, `BROKEN`. Порог доказанного движения — `+0,50%`; допустимый возврат сильного движения — `1,00%`; после предупреждения — `0,50%`. Эти значения не подбираются по результату EO4.

Порядок запуска обязателен: тесты → 10% одной старой монеты → полная одна монета → полный ALL9. Новые монеты не открываются до фиксации выводов и используются позднее как невиденная проверка.

После независимого расчёта траекторий выполняется хронологический replay: на одном symbol одновременно разрешена только одна позиция. Каждый заблокированный сигнал сохраняется в журнале вместе со ссылкой на занимавшую монету позицию. Более ранний Exit освобождает следующий Entry, более долгий runner может его заблокировать.
