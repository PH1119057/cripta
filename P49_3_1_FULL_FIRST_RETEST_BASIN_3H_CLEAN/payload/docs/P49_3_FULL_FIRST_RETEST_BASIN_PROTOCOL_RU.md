# P49.3 — Full First Retest Basin + 3h Risk Anatomy

## Статус

Research only. Downloads: DISABLED.

P49.3 не меняет Entry V1, frozen P46, live Execution, Exit или Risk. Пять новых резервных OOS-активов BNB/AVAX/SUI/AAVE/LTC не читаются этим исследованием.

## Фиксированная выборка

P49.3 использует ровно 995 старых Entry V1 сигналов из исходных 1063, которые сначала достигли +0.10% раньше исходного hard SL -1.00%.

66 early failures, у которых -1.00% был раньше +0.10%, в этот цикл не входят. Сигналы без подтвержденного +0.10 также не входят.

Источник состава выборки — завершенный P49.2 `first_retest_events.csv`; P49.3 проверяет точный count=995 и SHA256 источника.

## Терминология полного первого ретеста

До первого достижения +0.10 adverse-движение считается первоначальным Entry noise и не является ретестом.

После +0.10 формируется Peak #1. Peak #1 продолжает обновляться, пока цена не откатится от него минимум на 0.05 процентного пункта. Это causal-момент начала first retest.

После начала ретеста Peak #1 замораживается. Любые микробаунсы внутри отката не завершают ретест.

Полный первый ретест заканчивается только одним из трех событий:

1. цена causally reclaim'ит замороженный Peak #1 — `reclaimed_peak1`;
2. цена достигает исходного hard SL -1.00% раньше reclaim — `initial_stop_before_reclaim`;
3. доступные исторические данные заканчиваются раньше обоих событий — `unresolved` / right-censored.

`basin_low_pct` — самый глубокий direction-normalized уровень относительно Entry внутри полного первого ретеста. Для LONG и SHORT знак одинаков: отрицательное значение означает adverse move.

## Что измеряется

Основная матрица разбивает full first retest low по диапазонам:

- выше Entry;
- 0 … -0.25%;
- -0.25 … -0.35%;
- -0.35 … -0.50%;
- -0.50 … -0.60%;
- -0.60 … -0.75%;
- -0.75 … -1.00%;
- <= -1.00%.

Для каждого диапазона считаются reclaim Peak #1, failure к -1 и последующее возвращение к +0.10/+0.50/+1/+2/+3 до исходного -1.

## Трехчасовой срез

Для каждой из 995 сделок отдельно фиксируются первые 3 часа от Entry:

- min_3h_pct и его timestamp;
- max_3h_pct и его timestamp;
- первое достижение -0.25/-0.35/-0.50/-0.60/-0.75/-1.00 после +0.10;
- первое достижение -1 в первые 3 часа;
- лучший favourable move до первого -1;
- фактическая глубина после crossing -1 до конца 3h;
- raw recovery после -1 в пределах 3h — только описательно, потому что baseline trade к этому моменту уже закрыта исходным stop.

Для уровней выше -1 дополнительно считается, сколько сделок после достижения adverse threshold затем causally вернулись к Entry/+0.10/+0.50/+1/+2/+3 раньше исходного -1.

## Saved losers vs lost runners

Для заранее заданных candidate stops:

- -0.75%;
- -0.60%;
- -0.50%;
- -0.35%;
- -0.25%;
- +0.10%;

P49.3 моделирует два causal timing:

- `retest_start`: stop подтягивается в момент, когда retest causally начался;
- `peak1_reclaim`: stop подтягивается только после завершенного retest и reclaim Peak #1.

Для +0.50/+1/+2/+3 отдельно считаются:

- `baseline_runners` — target был бы достигнут раньше исходного -1;
- `runner_lost` — candidate stop убил бы такого runner;
- `baseline_initial_stop_losers` — исходный -1 был бы раньше target;
- `saved_losers` — candidate stop закрыл бы такой baseline loser раньше -1;
- horizon non-runners и right-censored rows не маркируются как saved losers.

`theoretical_price_risk_saved_*` — только price-move arithmetic, не net PnL и не economic break-even; комиссии, slippage и funding туда не входят.
