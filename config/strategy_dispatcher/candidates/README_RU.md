# Исследовательские кандидаты профилей

Этот каталог не является каталогом исполняемых профилей Диспетчера.

Файлы фиксируют четыре требуемых направления исследования M3, но не содержат
неподтверждённых правил и порогов. Поэтому у них:

- `status = RESEARCH_REQUIRED`;
- `enabled = false`;
- `trading_effect = NONE`;
- пустой список `rules`.

Диспетчер загружает только `config/strategy_dispatcher/profiles`. Перенос кандидата
в этот каталог разрешён только после причинного исследования, экономической
проверки комиссий и проскальзывания, фиксации версии и отдельного решения о режиме
SHADOW. Даже SHADOW-профиль не подключается к Entry, Risk, Exit или Execution.
