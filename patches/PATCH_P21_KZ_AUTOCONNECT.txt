P21 — KZ STARTUP AUTOCONNECT + ISOLATED PRE-CHECK DIAGNOSTICS
Date: 2026-08-15

Purpose
-------
1. LIVE desktop startup defaults to the Kazakhstan Mainnet stack.
2. Read-only connection starts automatically after the Qt window is created.
3. A temporary manual .com choice is not persisted across a normal restart.
4. Trading remains fail-closed: startup does NOT arm MICRO_LIVE and does NOT send an order.
5. /v5/order/pre-check is skipped for ISOLATED_MARGIN because Bybit documents that
   Pre Check Order supports Cross Margin and Portfolio Margin, not Isolated Margin.

Startup behavior
----------------
Normal START_WORKBENCH.cmd / START_MICRO_LIVE.cmd launch:
  REST       https://api.bybit.kz
  Public WS  wss://stream.bybit.kz/v5/public/linear
  Private WS wss://stream.bybit.kz/v5/private
  Read-only  starts automatically
  Execution  remains SHADOW / DISARMED until the existing arming flow is completed

An explicit BYBIT_WORKBENCH_REST_URL remains an operator override for diagnostics/scripts.
The shipped .cmd launchers clear that variable, so normal desktop startup selects .kz.
