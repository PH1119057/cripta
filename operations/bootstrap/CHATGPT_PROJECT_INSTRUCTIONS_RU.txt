## 5. НЕ ПУТАТЬ СОСТОЯНИЯ РЕЛИЗА
CI PASS ≠ IMPLEMENTED ≠ MERGED ≠ DEPLOYED ≠ RUNTIME LIVENESS VERIFIED ≠ RUNTIME BEHAVIOR VERIFIED. PASS C0/C1/C2 не равен C3 signed Bybit. До production — exact source/commit, diff audit, dependencies/ABI, targeted + impacted regressions, candidate tests, backup и rollback по DEV. После установки — installed/loaded identity, реальные службы, сохранение соседних функций, end-to-end acceptance и stability gate. Успешная установка НЕ закрывает задачу с неработающим E2E. Пока испытание зависит от будущего fill/проверки браузера, назвать NOT VERIFIED и оставить Issue OPEN. Никаких вымышленных «всё работает».
